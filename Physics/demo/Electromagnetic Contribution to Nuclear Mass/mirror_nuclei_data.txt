# ============================================================================
# EXPERIMENTAL DATA: MIRROR NUCLEI
# ============================================================================
#
# Each row is a mirror pair (Z, N) <-> (N, Z), with A = Z + N.
#   "parent" = the neutron-rich member, Z_p < N_p   (usually the stable one)
#   "mirror" = the proton-rich member,  Z_m = N_p, N_m = Z_p
#
# COLUMNS
#   A          mass number
#   parent     nuclide symbol of the neutron-rich member
#   Zp         proton number of the parent
#   mirror     nuclide symbol of the proton-rich member
#   ME_p       ATOMIC mass excess of parent, keV   [AME2020]
#   ME_m       ATOMIC mass excess of mirror, keV   [AME2020]
#   r_p        rms CHARGE radius of parent, fm     [Angeli & Marinova 2013 + updates]
#   r_m        rms CHARGE radius of mirror, fm     (nan = not measured)
#
# NOTES ON THE DATA
#   * Mass excesses are ATOMIC (that is how AME tabulates them). The script
#     converts to nuclear masses by removing (N-Z) electron masses.
#   * r is the rms charge radius. The script converts to the equivalent
#     UNIFORM-SPHERE radius via R = sqrt(5/3) * r_rms, which is the R that
#     belongs in E_C = (3/5) k Q^2 / R.
#   * Where r_m is nan, only the (usually stable) parent's radius is measured;
#     the script then uses the parent's radius for both members. This is the
#     "both mirror nuclei have almost the same R" assumption.
#   * The five pairs with BOTH radii measured (A = 3, 7, 18, 19, 32, 34, 36, 38,
#     54) allow the equal-radius assumption itself to be tested.
#   * Values are quoted to the precision of the compilations; the last digit or
#     two of the exotic proton-rich members (32Ar, 36Ca, 54Ni, 9B) carries
#     experimental uncertainty of order 1-50 keV. Re-verify against the primary
#     AME2020 tables before publishing anything.
#
# ============================================================================
